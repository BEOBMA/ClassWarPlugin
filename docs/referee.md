# 심판관 (referee)

- 법봉: 철 검. 기본 공격 2회 적중마다 Brightness 1, 기록된 죄가 있는 대상에게 기본 피해 +1.
- 강타: 4칸 시선 대상에게 짧게 도약한 뒤 피해 6. 죄가 있으면 Brightness 2. 재사용 10초.
- 기소: 10칸 시선 대상에게 10초간 이동 속도 -20%, 받는 피해 +20%. 기소 시 죄가 있던 대상은 그 10초 동안 Brightness 폭발마다 고정 피해 5. 재사용 40초.
- 대천칭: 죄가 있는 10칸 내 적 플레이어를 선택하고, 공용 영역 전조 후 반경 10칸의 법정에서 20초간 재판. 재사용 300초. 내부 전원 행동 제한·무적, 외부와 피해 교환 차단.

각 심판관은 자신의 원장에 폭행(최근 10초간 같은 대상에게 누적 피해 8)과 살인을 기록한다. 교전이 10초 이상 끊기면 선제 공격자 기록을 새로 시작한다. 피해자가 먼저 공격한 교전에서 발생한 행위는 정당방위 증거를 갖는다. 불법 감금·방화·도주는 설계 예시이며 현재 죄목에 포함하지 않는다.

가장 무거운 죄를 기소한다. 피고인은 선택창 또는 채팅(`인정`, `정당방위`, `부인`)으로 한 번 변론한다. 자백은 한 단계 감경, 사실과 일치하는 정당방위는 무죄, 허위 주장은 가중한다. 미응답은 원래 형량을 유지한다.

| 형량 | 효과 |
|---|---|
| 경형 | 10초간 이동 속도 -30% |
| 중형 | 5초간 침묵·무장 해제, 3초간 속박 |
| 가중 중형 | 보호막 제거, 8초간 침묵·무장 해제, 10초간 받는 피해 +30% |
| 사형 | 살인 재판에서 살인 기록 2건 이상이며 위증한 경우에만 처형 |

법정 해제와 원위치 복귀 후 형벌을 적용한다. 중도 취소에는 형벌을 적용하지 않는다. 재판이 시작된 뒤 종료되면 시전자의 원장을 초기화하고 20초간 이 클래스의 Brightness 부여를 막는다. 전조 중 취소에는 이 후유증이 없다. 공용 영역의 전조는 실제 3초이며, 재판·후유증 시간은 경기 일시정지 중 멈춘다.

실서버 확인: 아군을 포함한 법정 관객의 행동 제한, 선택창 클릭/드래그와 채팅 변론, 외부의 지속 피해 차단, 피고인/시전자 접속 종료, 클래스 제거, 경기 종료 시 지형·무적·이동 제한 복원, 다중 심판관의 독립 원장과 기소 효과.
