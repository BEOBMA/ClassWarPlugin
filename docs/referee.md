# 심판관 (referee)

- 법봉: 철 검. 기본 공격 2회 적중마다 Brightness 1, 기록된 죄가 있는 대상에게 기본 피해 +1.
- 강타: 4칸 시선 대상에게 짧게 도약한 뒤 피해 6. 죄가 있으면 Brightness 2. 재사용 10초.
- 기소: 10칸 시선 대상에게 10초간 이동 속도 -20%, 받는 피해 +20%. 기소 시 죄가 있던 대상은 그 10초 동안 Brightness 폭발마다 고정 피해 5. 재사용 40초.
- 대천칭: 죄가 있는 10칸 내 적 플레이어를 선택하고, 공용 영역 전조 후 반경 10칸의 법정에서 20초간 재판. 재사용 300초. 내부 전원 행동 제한·무적, 외부와 피해 교환 차단.

각 심판관은 자신의 원장에 폭행(최근 10초간 같은 대상에게 누적 피해 8)과 살인을 기록한다. 교전이 10초 이상 끊기면 선제 공격자 기록을 새로 시작한다. 피해자가 먼저 공격한 교전에서 발생한 행위는 정당방위 증거를 갖는다. 불법 감금·방화·도주는 설계 예시이며 현재 죄목에 포함하지 않는다.

가장 무거운 죄를 기소한다. 선택창은 생성하거나 열지 않는다. 피고인에게 선택지를 채팅으로 안내하며 채팅(`인정`/`1`, `정당방위`/`2`, `부인`/`3`)으로만 한 번 변론한다. 잘못된 입력은 재안내하며 응답으로 확정하지 않는다. 자백은 한 단계 감경, 사실과 일치하는 정당방위는 무죄, 허위 주장은 가중한다. 미응답은 원래 형량을 유지한다.

| 형량 | 효과 |
|---|---|
| 경형 | 10초간 이동 속도 -30% |
| 중형 | 5초간 침묵·무장 해제, 3초간 속박 |
| 가중 중형 | 보호막 제거, 8초간 침묵·무장 해제, 10초간 받는 피해 +30% |
| 사형 | 살인 재판에서 살인 기록 2건 이상이며 위증한 경우에만 처형 |

법정 해제와 원위치 복귀 후 형벌을 적용한다. 중도 취소에는 형벌을 적용하지 않는다. 재판이 시작된 뒤 종료되면 시전자의 원장을 초기화하고 20초간 이 클래스의 Brightness 부여를 막는다. 전조 중 취소에는 이 후유증이 없다. 공용 영역의 전조는 실제 3초이며, 재판·후유증 시간은 경기 일시정지 중 멈춘다.

실서버 확인: 아군을 포함한 법정 관객의 행동 제한, 메뉴가 열리지 않는지와 채팅 변론·중복 응답 제한, 외부의 지속 피해 차단, 피고인/시전자 접속 종료, 클래스 제거, 경기 종료 시 지형·무적·이동 제한 복원, 다중 심판관의 독립 원장과 기소 효과.

## 전용 시청각 연출

심판관은 법정 구조물 배치 후 영역 내부의 빈 공간을 밝기 15의 실제 `LIGHT` 블록으로 채운다. 검은 장막과 법정 구조물은 덮어쓰지 않는다. 빛 블록은 투명하고 통과 가능하며, 해제 연출의 블록 디스플레이 대상에서 제외한다. 정상 종료·취소 시 기존 지형 및 기존 빛 블록의 밝기까지 공용 복원 기록으로 되돌린다. 다른 영역의 조명 설정은 기본적으로 변경하지 않는다.

기존 END_ROD 천칭·산개 입자, 모루/인챈트 소리, 공용 보라색 마법진·포탈/폭발음은 심판관에서 사용하지 않는다.
`RefereeEffects`와 `RefereeCourtEffects`가 대체하며 다른 클래스의 기본 영역 연출은 유지한다.

- 광휘 부여: 재빛 증거 인장과 가는 수직 흔적, 낮은 스컬크음.
- 강타: 도약 인장과 쇠사슬 마찰음 → 내려찍는 빛과 교차 인장, 묵직한 금속·목재 타격음.
- 기소: 붉은 봉인과 머리 위 표식, 서류 넘김·책장 삽입음.
- 전개: 실제 검은 콘크리트 장막, 진홍색 봉인과 끊어져 오르는 균열·낮은 연무. 밝은 하프 화음을 제거하고 저음·충격음으로 공간이 봉쇄되는 느낌을 만든다. 법정은 심층암·흑암 재질로 바꾸되 가구의 좌표는 유지한다.
- 장막은 아래쪽까지 포함한 구체이며 공중 시전 시에도 바닥을 먼저 확보한다. 한자 타이틀을 `영 역 전 개`로 변경하고 기본 표시 시간을 1.8초에서 2.6초로 늘린다. 재판의 20초는 타이틀 종료 후 시작한다.
- 재판: 재빛 대천칭이 흔들리며 변론 접수 후 안정된다. 답변의 정오를 미리 노출하지 않는다. 바닥 눈금과 마지막 5초의 빨라지는 심장 박동으로 마감을 알린다. 남은 시간은 공용 `영역` 상태에서만 표시하여 다른 상태이상의 액션바를 덮어쓰지 않는다.
- 판결: 무죄는 어두운 비취색·해제음, 유죄는 진홍색·타격음. 새 선고 타이틀을 표시한다.
- 종료: 붉은 인장이 수축하고 연무와 낮은 파열음을 재생한다. 장막 블록은 위에서 아래로 원상 복원한다.

연출은 기존 세션/스킬의 수명과 전투 틱을 사용하며 별도 반복 타이머를 만들지 않는다. DUST는 색상 데이터를 명시하고 고정 표본 수를 사용한다. 피해·재판·연습 모드 규칙은 변경하지 않는다.
