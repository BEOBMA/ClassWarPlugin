# 특수 피해 표시

일반 피해는 기존의 빨간 숫자를 유지한다. 특수 피해는 사진 레퍼런스의 굵은 외곽선·기울기·밝은 그라데이션·등장 시 확대 후 정착하는 형태를 적용한다. 별도 리소스팩이나 사용자 폰트 파일을 요구하지 않는다. 고정 피해 숫자는 내장 `minecraft:uniform` 서체를 사용하며, 원본 사진의 글꼴을 동일하게 복제하지는 않는다.

- 진동 폭발: 황금색 `진동 폭발`과 숫자, 확대·짧은 좌우 진동.
- 처형: 붉은 `처형` 전용 문구. 내부 판정용 체력+2048 등의 숫자는 피해량인 것처럼 노출하지 않는다.
- 고정 피해: 금빛 이름·숫자·내장 숫자 서체. 최종 자기장 고정 피해도 포함한다.
- 출혈·빙결 파쇄·화상·독·시듦·마법·폭발·낙뢰·회복 반전: 각기 다른 명칭·색상·크기.
- 분류되지 않은 상태 피해도 일반 피해 대신 `상태 피해`로 표시한다.

`DamageAppearance`는 계산에 관여하지 않는 표시용 정보다. `PlayerManager.damage(..., appearance = ...)`에서 구체적인 연출을 선택하고, 생략 시 DamageType/경로로 기본 분류한다. 팬텀의 피해 위임에도 정보를 보존한다. 체력을 직접 0으로 만드는 처형은 기존 판정 직전에 `showExecution`만 호출한다. 피해량·보호막·무적·처형 성공 여부는 변경하지 않는다.

특수 표시마다 본문 1개와 외곽선 4개의 TextDisplay를 사용한다. 동시에 최대 80개 표시(최대 400개 디스플레이), 수명 최대 44틱으로 제한하며 본문/외곽선을 같은 작업에서 이동·페이드·제거한다. 기존 피해 표시 설정이 꺼지면 생성하지 않는다. 경기 종료와 플러그인 종료 시 모든 레이어를 함께 정리한다.

실서버 확인: 연습 모드의 플레이어/몹/더미에 진동 폭발·출혈·빙결 파쇄·고정 피해, 처형, 화상. 카메라 각도별 외곽선 겹침과 글자 가독성, 다중 연타 시 표시량, 경기 종료 후 남는 텍스트 유무.
