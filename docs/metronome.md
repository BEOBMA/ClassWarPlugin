# 메트로놈: 가변 박자

## 능력과 공통 박자 시계

- B등급, 기본 무기 철 검. 일반 클래스 목록·훈련·성장 모드에 등록한다.
- 공격 속도 효과를 적용하여 틱 간 기본 공격이 충전된다. 같은 적의 정박 공격에서는 바닐라 피격 무적 시간을 해제한다. 무적 상태이상과 기존 공격 제한은 별도로 적용한다.
- 대기 중에는 60 BPM으로 시작한다. 음악이 시작되면 클릭·공격 판정·액션바·진자도 **현재 곡의 BPM과 동일한 시계**를 사용한다.
- 2·4분할 공격을 지원하고, 72 BPM 이하에서는 8분할도 지원한다. 음표와 판정을 동일한 정수 틱에 배치한다. 한 격자 중복 사용과 같은 틱 중복 패킷으로 추가 피해나 연속 기록을 얻을 수 없다.
- 허공 좌클릭으로도 박자를 연습할 수 있다. 엇박 피해는 다른 적중 훅 전에 취소된다. 별도 프로그램 투사체 등 기본 공격 경로의 피해는 피해 발생 시점을 판정한다.
- 연속 정박 피해 배율은 `1 + min(1.5, 연속 횟수 × 0.015 + 유지 초 × 0.005)`이다. 엇박 또는 마지막 정박 이후 40틱을 넘긴 공백은 기록과 음악을 초기화한다.
- 연속 정박 8회마다 다음 곡이 해금된다. 최근 공격 간격에 따라 초당 1.6회 이하이면 최대 4곡째, 3.2회 이하면 10곡째, 5회 이하면 16곡째, 더 빠르면 24곡째까지 진행한다. 곡은 마디 첫 박에서 한 단계씩 올라간다.
- 음악은 시전자에게 노트블록 사운드로 재생한다. 액션바에 곡명, 실제 판정 BPM, 분할 수, 연속 횟수와 정박/엇박 결과가 표시된다.

## 직접 작곡한 모음곡: 진자의 스물네 장면

기존 곡이나 MIDI를 사용하지 않고 각 곡의 질문·응답 선율, 화성 진행, 리듬을 직접 작성했다. 모두 4/4박자 8마디이며 같은 템포의 두 곡도 서로 다른 선율·화성을 가진다.

| BPM | 곡 |
| --- | --- |
| 60 | 첫 진자 / 새벽의 물방울 |
| 66 | 안개 속 우편 / 작은 등대 |
| 72 | 유리 계단 / 햇살의 태엽 |
| 80 | 은빛 나침반 / 종이비행의 궤적 |
| 88 | 푸른 역의 왈츠빛 / 나무 사이의 바람 |
| 96 | 맥박의 행진 / 구리빛 기관 |
| 108 | 별자리 추적 / 불꽃의 초대 |
| 120 | 수평선 너머 / 폭풍 전의 약속 |
| 132 | 붉은 궤도 / 천 개의 등불 |
| 144 | 심장의 도약 / 빛을 향한 질주 |
| 160 | 새벽의 질주 / 유성의 약속 |
| 180 | 마지막 태엽 / 일출의 피날레 |

초반 6곡은 하프·기타·베이스의 여백 있는 편곡, 다음 6곡은 플루트와 하프 아르페지오, 다음 6곡은 플링과 드럼 리듬, 마지막 6곡은 비트 주선율·벨·플루트 대선율·드럼 필인으로 고조된다. A·C·D·G·E를 중심으로 장조와 단조를 교차하고, 후반 네 마디에서 선율을 변형해 전개한다. 음역은 노트블록 키 0~24, pitch 0.5~2.0을 지킨다.

## 동기화 수정

기존에는 음악의 BPM과 별개로 클릭과 판정이 60 BPM에 고정되어 있었다. 미리듣기의 첫 음도 클릭보다 한 틱 늦었다. 현재는 한 번의 재생 프레임이 음악·클릭·판정·표시를 함께 결정하고 첫 음과 클릭을 같은 프레임에서 낸다.

악보 위치를 4분음표당 8펄스로 저장하고 각 이벤트의 절대 음악 위치를 실제 서버 틱으로 변환한다. 반올림한 마디 길이를 더하거나 반올림한 곡 길이를 반복하지 않으므로 66·88·108 BPM 등의 긴 반복에서도 오차가 누적되지 않는다. 서버의 20 TPS 해상도에 따른 개별 음의 최대 반 틱 양자화는 음표와 판정에 동일하게 적용한다.

## 훈련 미리듣기와 수명

훈련 모드에서는 성공 조건 없이 24곡을 각각 끝까지 재생하고 반복한다. 검을 들고 **F**를 누르면 다음 곡, **웅크리기 + F**를 누르면 미리듣기 켜기·끄기이다. 액션바에 현재 곡 번호/24가 표시된다. 엇박과 공격 공백은 미리듣기를 멈추지 않는다. 피해 판정과 피해 보상은 실제 입력에 따른다.

클래스 전용 전투 시계와 `AbilityRunnable`이 함께 일시 정지된다. 사망·종료·클래스 제거 시 재생 작업과 공격 속도 효과를 해제한다. 재접속 및 수동 곡 선택은 새 곡 첫 박에서 재생한다.

검증은 전체 미리듣기 순환, 모든 클릭과 판정·표시의 일치, 모든 BPM의 분할 공격, 24곡의 서로 다른 주선율, 음역·화성·동시 발음 수, 곡당 12회 반복의 누적 오차, 마디 첫 박에서의 단계 전환을 포함한다. 실제 서버의 청감과 네트워크 지연에 따른 입력 감각은 별도 플레이 확인이 필요하다.
