# 통합 표식 아이콘

파일: `resource-pack/assets/classwar/textures/status/resonance_mark.png`

내장 image_gen으로 생성한 투명 PNG 원본이다. 빌드 시 기존 처리로 32px 텍스처를 만든다.
`ResonanceMark`는 UI 전용 아이콘이며 게임플레이 키워드가 아니다.

생성 프롬프트:

> Create one new game status icon combining aftermath and resonance into ONE unified silhouette. Use case: stylized-concept, bitmap game UI asset. Transparent RGBA background, square canvas. Simple flat geometric emblem readable at 32x32: a four-point golden impact spark embedded within a purple resonant diamond core, with two thick gold echo arcs integrated on its sides. Only 4 flat colors: dark violet #72349B, purple #A45BD4, ochre gold #D69D20, pale gold #FFE47A. Angular strong silhouette, large clean negative spaces, minimal shapes. No text, no digits, no border, no surrounding UI, no gradient, no glow, no 3D shading, no tiny details. Match the simple flat silhouette aesthetic of Minecraft custom status keyword icon drafts. The whole emblem is one centered cohesive symbol, not two separate icons. Genuine transparent background. Keep 12 percent clear padding.
