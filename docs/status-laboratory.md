# 상태이상 실험실

OP 권한과 `internal.testing.commands-enabled: true`가 필요하다. 일반 경기 중에는 들어갈 수 없으며 기존 클래스 연습은 먼저 `/cw exit`로 종료한다.

- `/cw test status`: 개인 연습을 시작하고 아이템 목록을 연다. 이미 실험 중이면 다시 목록을 연다.
- `/cw test status 20 15`: 이후 사용하는 아이템의 수치를 20, 지속시간을 15초로 정한다. 각 상태의 자체 최대 수치는 유지한다.
- `/cw test status clear`: 자신이 이 실험실에서 적용한 상태를 해제한다.
- `/cw exit`: 원래 인벤토리와 플레이어 스냅샷을 복구하고 연습을 종료한다.

책 우클릭으로 페이지 목록을 열고 원하는 상태를 클릭하여 적용 아이템을 받는다. 적용 아이템 우클릭은 자신, 근접 타격은 대상에게 적용한다. 적용 도구 자체는 공격 피해를 입히지 않는다. 우유 아이템은 우클릭 시 자신이 적용한 실험 효과를 일괄 해제하며, 타격 시 해당 대상의 실험 효과를 해제한다. 실제 공격 반응은 기본 지급 철 검으로 확인할 수 있다.

다른 플레이어는 `/cw test status`에 참가한 경우만 대상으로 삼는다. 등록된 연습 몹/더미도 대상이 된다. 아이템에는 실험 세션 식별자가 있어 다른 플레이어·종료된 세션에서는 작동하지 않는다. 버리기·보관함 반출은 차단한다.

`status/list`의 공개 상태 구현 50종을 모두 등록하며 자동 테스트로 누락을 검사한다. 마나·탄환·체크포인트·지령·시간대 등 클래스 자원은 실제 상태 객체/표시를 테스트하지만, 이를 소비하는 원래 클래스의 스킬까지 자동으로 부여하지 않는다. 왜곡 역시 영역이 관리하는 시간 제어와 별개인 표시 상태다. 클래스 내부의 비공개 세션/전용 표식은 이 공용 목록에 포함하지 않으므로 해당 클래스 연습에서 확인한다.

진동 폭발은 진동이 없을 때 지정 수치의 진동을 먼저 넣는다. 동상·광채·감전 등은 원래의 임계치 변환 규칙대로 빙결·속박·기절로 바뀔 수 있다. 지속시간이 없는 자원도 실험에서는 지정 시간이 지나면 제거한다. 하나의 세션 시계로 만료를 관리하여 사용 횟수만큼 타이머를 생성하지 않는다.
