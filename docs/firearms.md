# 총기 클래스

신규 클래스 ID와 설명의 이름·등급·무기 재질을 유지하여 사냥꾼, 돌격대, 특수대원, 중화기병, 총기의 달인을 구현한다.
클래스 선택·훈련·성장 모드의 카탈로그에 모두 등록한다. 일반 성장 계수와 재장전 시간 계수를 적용하되 탄창 크기는 설명의 고정값을 유지한다.

## 사격과 재장전

| 클래스 | 탄창 / 발사 소모 | 사격 | 재장전 | 제약 |
| --- | --- | --- | --- | --- |
| 사냥꾼 (`hunter`) | 4 / 2 | 20개 산탄, 산탄당 1 피해, 대상별 최대 8개 | 4초, 스킬 쿨다운 6초 | 재장전 중 이동 속도 -60% |
| 돌격대 (`sturmtruppe`) | 30 / 1 | 탄환당 0.2 피해 | 3초, 스킬 쿨다운 8초 | 재장전 중 이동 속도 -30% |
| 특수대원 (`spezialeinheitsmitglied`) | 20 / 1 | 탄환당 0.2 피해 | 탄창 소진 또는 마지막 사격/교전 후 6초에 자동 2초 재장전 | 탄창이 가득 차면 불필요한 자동 재장전 없음 |
| 중화기병 (`schwerekavallerie`) | 300 / 1 | 탄환당 0.1 피해 | 10초, 스킬 쿨다운 30초 | 소지 중 이동 속도 -80%, 재장전 중 -90%, 두 경우 모두 점프 불가 |

전투 시작 시 탄창은 가득 찬다. 수동 재장전은 잔탄을 버리고 시작하며, 완료 전에 사격할 수 없다.
전투 일시정지·클래스 정지 중에는 재장전 시계도 정지한다. 이동 제한은 무기를 바꾸어도 재장전이 끝날 때까지 유지한다.
스코프 자원으로 속성과 탄환 상태를 소유하여 클래스 제거·사망·훈련/경기 종료 시 해제한다.
탄환 키워드 상태는 이름·숫자·남은 초 대신 탄약 실루엣을 표시한다. 밝은 탄환은 잔탄, 어두운 탄환은 빈 자리이다.
산탄총은 개별 산탄, 돌격소총은 굽은 탄창, 기관단총은 짧은 직선 탄창으로 표시한다.
미니건은 접힌 예비 탄띠(각 30발)와 현재 급탄 중인 30발 탄띠를 분리하여 화면 폭을 제한한다. 급탄부는 매 발마다 감소한다.
발사·재장전 시작 시 즉시 공통 액션바를 갱신하고, 재장전 중에는 매 틱 변경된 프레임만 전송하여 다른 상태이상도 함께 유지한다.
재장전은 산탄 삽입, 탄창 분리·교체·노리쇠 조작, 급탄 덮개 열기·탄띠 삽입·잠금 순서로 표현한다.
애니메이션은 성장 보정된 실제 재장전 시간에 맞추며, 시각적으로 탄환이 삽입되어도 실제 사격은 재장전 완료 후에만 가능하다.

설명에 지정하지 않은 조작 수치는 공통 `FirearmProfile`에 둔다. 기본 20 TPS 기준:

- 산탄총: 발사 간격 14틱(0.7초), 사거리 24블록, 강한 시점 반동과 후방 밀림.
- 돌격소총: 발사 간격 2틱, 사거리 48블록, 기관단총보다 강한 시점 반동.
- 기관단총: 발사 간격 2틱, 사거리 36블록, 약한 시점 반동.
- 미니건: 발사 간격 1틱, 사거리 48블록, 넓은 산포와 연사 중 누적 반동.

자동 총기는 Paper의 소비 가능 아이템/사용 효과 컴포넌트로 실제 우클릭 유지 상태를 읽는다.
소비 시간은 1시간이며 소비 이벤트는 차단한다. 음식·방패의 기본 이동 감속은 사용하지 않는다.
버튼 해제·주 손 변경·무장 해제·공격/스킬 금지 시 연사를 중단한다. 특수대원은 우클릭을 계속 유지하면 자동 재장전 완료 후 연사를 이어간다.
시점 반동은 상대 회전 패킷으로 여러 틱에 분산해 플레이어의 마우스 조작을 덮어쓰지 않는다.

탄도는 눈 위치부터 벽까지 즉시 레이 검사를 하며, 모든 엔티티 교차는 `entity.boundingBox`로 계산한다.
각 산탄은 원판 분포의 독립 난수 방향으로 퍼지고 첫 대상에서 멈춘다. 하나의 발사에서 대상별 산탄 수를 집계하여 최대 8 피해를 한 번 적용한다.
훈련의 등록된 생명체, 성장 몬스터·동물도 같은 피해 경로를 사용한다. 아군·무적·보호막 등 기존 전투 규칙을 유지한다.
신규 총기는 `SKILL` 피해 경로를 사용해 설명의 0.1/0.2 수치에 기본 공격 전용 0.6 배율을 추가 적용하지 않는다.
총구 화염·연기, 짧은 탄도, 충돌 파티클, 총기별 음높이/음량, 재장전 잠금/해제 소리를 재생한다. 실제 블록은 변경하지 않는다.

## 총기의 달인 (`firearmsmaster`)

교체 대상은 사냥꾼·돌격대·특수대원·중화기병·총검사·저격수·마탄의 사수 7종이다.
현재 총기를 후보에서 제외하므로 같은 총기가 바로 연속으로 나오지 않는다. 장전된 모든 탄약을 소진하면 마지막 사격 처리가 끝난 다음 틱에 교체한다.
마탄의 사수는 일반 6발과 마탄 1발을 모두 소모해야 한다. 총검사는 현재 성장 탄창 최대치로 시작한다.

복사한 효과는 원본 클래스 인스턴스를 자식 능력으로 구동한다:

- 수동 재장전 스킬은 지급하지 않는다.
- 특수대원의 자동 재장전, 마탄의 사수의 자동 재장전, 총검사의 3타/비전투 탄약 충전은 비활성화한다.
- 총검사의 돌파·전탄 격발·진동, 저격수의 조준·F 사격·저지력, 마탄의 사수의 패닝/퀵드로우·마탄 부작용을 유지한다.
- 중화기병의 무기 소지 감속/점프 금지도 유지한다.

교체 시 이전 자식 능력의 작업·탄약 표시·속성 기여분을 종료하고 새 능력을 주입한다.
해당 달인의 무기와 인스턴스 ID가 일치하는 스킬 아이템만 교체한다. 시작 아이템을 다시 지급하지 않는다.
기존 저격수·총검사·마탄의 사수도 인스턴스별 탄약 표시를 사용하여 듀얼/복사 능력의 탄약이 공유되지 않는다.
저격수의 일반 재장전은 사용자가 변경한 설명대로 장전된 탄환이 있어도 버리고 다시 장전할 수 있다.

## 검증

자동 테스트로 탄창 소모·연사 간격·재장전 완료 틱·산탄 최대 피해·소수 피해·수직 조준 산포·바운딩 박스/벽 거리·교체 후보·카탈로그/성장 등록을 확인한다.
실제 Paper 서버에서 우클릭 유지/해제 패킷, 반동 체감, 소리 크기, 듀얼 모드 교체와 훈련 종료 후 상태 복원은 별도 플레이테스트가 필요하다.
