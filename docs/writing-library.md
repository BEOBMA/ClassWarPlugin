# 작가 글 라이브러리

`WritingLibrary`에는 기존 20종과 추가 40종, 총 60종을 수록한다.
추가 구성은 이상 8종, 윤동주 12종, 김소월 12종, 고전 시가 7종, 김상용 1종이다.
오감도는 각 시제 번호를 별도 작품으로 취급한다.

## 입력용 표기

- 저작권이 만료된 한국어 원작을 사용한다. 현대 번역문이나 노래 편곡의 가사를 옮기지 않는다.
- 한자는 한글로 풀고 옛 철자와 띄어쓰기는 입력 가능한 표기로 정리한다. 학술용 원문 전사가 아닌 게임용 입력문이다.
- 이상의 「거울」과 「오감도 시제1호」는 붙여쓰기를 유지한다. 숫자는 일반 숫자 키로 입력한다.
- 긴 작품은 일부를 발췌하고 제목 끝에 `중에서`를 붙인다. 산문은 문장 또는 구절 단위로 나눈다.
- 인용부호 등 일부 문장 부호는 입력용으로 생략한다. 채점 기준은 화면에 표시된 문자열이며 공백과 남아 있는 문장 부호도 일치해야 한다.
- 빈 줄, 숨은 문자, 채팅 길이 제한(256자)을 넘는 줄은 넣지 않는다.
- 작품 추가는 출제 목록만 확장한다. 기존 섞기 방식과 정답·오답 보상은 유지한다.

## 원문 참고

- 이상: [거울](https://ko.wikisource.org/wiki/거울), [날개](https://ko.wikisource.org/wiki/날개), [오감도](https://ko.wikisource.org/wiki/오감도)의 시제1·3·5·9·10·12호.
- 윤동주: [하늘과 바람과 별과 시, 1948년판](https://ko.wikisource.org/wiki/하늘과_바람과_별과_시_(1948년))의 서시, 별 헤는 밤, 자화상, 길, 새로운 길, 쉽게 씌어진 시, 십자가, 또 다른 고향, 바람이 불어, 참회록, 봄. 「눈 감고 간다」는 별도로 추가한 발췌문이다.
- 김소월: [진달래꽃 시집](https://ko.wikisource.org/wiki/진달래꽃_(시집))의 먼 후일, 초혼, 엄마야 누나야, 못 잊어, 예전엔 미처 몰랐어요, 가는 길, 접동새, 개여울, 왕십리, 금잔디, 부모, 나는 세상 모르고 살았노라.
- 고전 시가: 이색 「백설이 잦아진 골에」, 길재 「오백 년 도읍지를」, 성삼문 「이 몸이 죽어 가서」, 원천석 「흥망이 유수하니」, 황진이 「산은 옛 산이로되」, 송순 「십 년을 경영하여」, 정철 「장진주사」.
- 김상용: [남으로 창을 내겠소](https://ko.wikisource.org/wiki/남으로_창을_내겠소)의 도입부.
