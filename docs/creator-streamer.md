# 창조자 / 스트리머

창조자는 능력 카탈로그와 성장 모드 분류에 등록되며 기존 SPECIAL 접근 정책을 그대로 따른다. 스트리머는 구현을 보존한 채 보류한다. 경기 배정·연습·클래스 목록·밸런스 설정에서 제외되며, 직접 생성 요청과 설정 변경도 차단한다. 기존 설정 파일의 스트리머 값은 읽지 않으며, 설정만으로 재활성화할 수 없다.

## 창조자

- 사슬: 마나 10, 20칸 블록 지정, 최대 24칸 위에서 내려오는 다중 IRON_CHAIN 디스플레이, 폭 1칸 경로 피해 2, 최대 10개. 착지 시 저음의 중량감 있는 금속 충격음을 겹친다.
- 사슬은 40% 확률로 수직, 60% 확률로 약 7~16도 기울어져 내려온다. 모든 마디는 고정된 상공 시작점과 사슬 끝을 잇는 축에 정렬된다. 창조 공간에서 시전한 사슬은 기본 쿨타임 2틱(0.1초), 적중 피해 0.2이며, 공간 밖에서는 20틱/피해 2다. 파괴의 감속·속박 효과는 유지한다.
- 빛의 창: 마나 30, 빠른 관통 경로 검사로 첫 대상 피해 5, 벽이나 대상에 고정, 최대 3개.
- 파괴: 마나 50. 사슬은 반경 2, 감속 20%/4초, 같은 대상에게 5초 내 5회면 속박 2초. 창은 반경 3, 피해 2.
- 한도를 넘으면 가장 오래된 같은 종류의 생성물을 효과 없이 제거한다.
- 창조 공간: 공통 영역 전개 연출 후 반경 25(지름 50)/15초. 금색 동심원 바닥, 8개 석영 기둥과 버팀 구조, 천장의 왕관형 환형 구조와 사슬 조명을 설치한다. 영역 내 가까운 적을 추적하며 지형에 막히지 않는다. 마나 비용을 무시하고 실제 마나 액션바 표시를 ∞로 바꾼다. 생성물은 생성 1초 후 파괴되며 기존 생성물도 영역 시작 1초 후 파괴된다.
- 영역 종료 시 생성물과 무한 마나 표시를 제거한다. 기본 마나는 100, 초당 회복 10이며 종료 후 20초간 회복량 1이다.
- 생성물 수, 영역 중 무한 마나, 회복 저하 시간을 액션바에 표시한다. 피해/범위는 entity.boundingBox 기준이다.
- 품질 강화: 소환 문양과 착탄 인장, 창날·발광 창대·금속 연결부의 복합 디스플레이, 고정된 생성물의 잔광, 8틱간 확장되는 파괴 충격파, 사슬을 따라 흩어지는 파편을 추가한다. 충격파는 시각 효과이며 피해 판정은 기존 시점에 한 번만 발생한다.
- 영역 건축에 회랑 아치·유리 장식벽·다면체 창조 핵·교차 천장 고리를 추가한다. 활성화 시 기둥에서 핵으로 빛이 모이며, 유지 중에는 기둥 조명이 순환한다. 해체는 기존 영역 복구 절차를 따른다.
- 성능: 소환 문양당 30개 점, 동시 파괴 충격파 최대 8개, 동일 종류 효과음 최소 5틱 간격. 모든 애니메이션은 소유 클래스/영역의 기존 작업에서 갱신되어 별도 무기한 작업을 만들지 않는다.

## 스트리머

**보류 중.** 아래는 재개를 위해 보존한 구현 기록이며 현재 게임에서는 사용할 수 없다.

실제 방송 서비스와 연결하지 않는 **가상 방송**이다. 상황별 창작 채팅과 무작위 닉네임(가끔 경기 참가자 이름)을 개인 사이드바에 표시한다. 액션바에는 시청자/치즈를 표시한다. 종료/클래스 전환 시 자신이 설치한 보드만 원래 보드로 복원한다.

설명에 없던 기본 밸런스는 `BroadcastRules`에서 분리한다.

- 시청자 1,000명 시작, 초당 1% 감소(최소 1명), 유효 피해를 주거나 받으면 최소 200명 또는 현재의 10% 증가. 흥분 이벤트는 초당 1회로 제한한다.
- 기본 공격 증가 = 시청자 / 100,000 (최대 +100%), 받는 피해 감소는 그 절반(최대 50%).
- 흥분 이벤트의 후원 확률 15~65%, 금액은 시청자 수의 0.5~2배(최소 100). 누적 치즈는 구매에만 사용한다.
- **한 번의 후원**이 충족하는 최고 단계 효과 하나를 자신 또는 가장 가까운 적에게 무작위 적용한다.
- 모루: 떨어지는 디스플레이, 닿은 대상에 피해 4, 생성 5초 후 제거. TNT: 디스플레이로만 표시, 2초 후 반경 4 피해 6. 두 효과 모두 블록을 바꾸지 않으며 시전자/적(연습 몹 포함)만 피해를 받는다.
- 장비 압수는 단일 보관함으로 관리하며 중첩 적용 시 복제하지 않는다. 대상 종료/사망/퇴장 및 효과 종료 시 정리한다. 압수 중 아이템 이동·획득은 잠시 제한한다. 전원 이동은 현재 경기의 생존 플레이어만 대상으로 한다.
- 상점: 철 검/활/화살/다이아 검, 철 갑옷, 치유·신속 물약, 황금 사과, 토템. 가격은 `BroadcastRuntime.products`에 명시한다. 잔액·소유자·빈 슬롯·전투 상태를 검증한 뒤 지급한다.

실제 서버 확인 권장: 공중/벽/움직이는 대상에 생성물 적중, 5연속 사슬 파괴, 영역 종료 정리, 후원 압수 중 사망·중첩·클래스 전환, 상점 클릭/드래그, 다른 사이드바 플러그인과의 공존.
