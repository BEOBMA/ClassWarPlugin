
### 신규 고유 효과 24종

고유 효과는 총 44종이다. 아래 각 효과에 스탯 구성 21개 × 3등급 = 63종을 추가하여 총 1,512종을 확장했다.
모든 조건은 적중 시점의 상태로 판정하며 고정 피해에는 적용하지 않는다. 거리 기준은 공격자와 대상의 현재 위치다.
밤은 월드 시간 13000~22999틱이다. 서로 다른 효과는 곱연산하며 같은 효과는 중첩되지 않는다.
몬스터의 근접/투사체 공격에도 방어 효과를 적용하며, 낙하·환경 피해에는 적용하지 않는다.

| --- | --- |
| 분쇄자의 대검 | 근접 기본 공격 피해 +14% |
| 명사수의 조준경 | 원거리 기본 공격 피해 +16% |

| 도전자의 칼날 | 플레이어에게 가하는 피해 +12% |
| 검막 갑주 | 받는 근접 기본 공격 피해 12% 감소 |
| 화살막 갑주 | 받는 원거리 기본 공격 피해 15% 감소 |
