# 여진·공명 표식

대상 머리 위의 원은 시계 방향으로 채워진다. 공명 1개는 120도이며,
여진 1은 다음 구간의 4도다. 공명 1·여진 15이면 180도다.
여진 30에 도달하면 여진을 제거하고 공명 1을 얻는다. 최대 공명은 3이다.
공명 3에 도달하면 남은 여진도 제거되며 여진을 추가로 얻을 수 없다.
차단된 여진 획득 시도로 공명의 지속시간이 갱신되지는 않는다.
공명을 소모해 3 미만이 되면 여진을 다시 쌓을 수 있다.
공명 또는 여진을 얻으면 두 상태의 남은 시간이 10초로 갱신된다.
공명 소모는 지속시간을 갱신하지 않는다.

보라색은 완성된 공명 구간, 금색은 여진 진행도다. 12·4·8시에 경계선이 있다.
중앙에는 전용 여진·공명 통합 아이콘 하나만 표시하며 수치는 표시하지 않는다.
리소스팩이 없으면 아이콘만 생략되며 원형 게이지는 그대로 표시된다.
자기 머리 위 표식은 자신에게 보이지 않는다. 다른 대상의 표식은 24칸 이내에서
대상이 보이고, 공명·여진을 부여하거나 소모하는 활성 능력을 가진 플레이어만 볼 수 있다.
클래스/스킬/패시브에 `ResonanceResourceUser`를 구현해 이 능력을 명시한다.
능력 제거·교체 또는 비활성화 시 아이콘과 게이지 모두 숨긴다.
원소술사의 동명 원소 공명은 해당되지 않는다. 상태이상 실험실은 테스트용으로
이 기능을 제공하며, 실험실에서도 자신의 표식은 숨긴다.

## 실험

기존 테스트 명령 사용 권한 및 설정을 활성화한 뒤 `/cw test status 1 10`을 사용한다.
여진 아이템으로 대상을 반복 타격하면 1씩 쌓인다. 30회마다 공명 1로 바뀐다.
공명 아이템으로 타격하면 공명을 직접 더한다. 웅크린 상태에서 공명 아이템으로
타격하면 공명 1을 소모한다. 우클릭은 자신에게 같은 동작을 적용한다.
자원은 자체 10초 갱신 규칙을 사용하며 실험실의 지속시간 설정보다 우선한다.

스킬에서는 대상의 `Aftermath`/`Resonance`를 `getOrCreateStatus`로 얻어
`increasePower`로 부여한다. 모든 사용 조건을 통과한 후 `Resonance.consume()`이
true인 경우에만 강화 효과를 적용한다. 성공한 소모는 대상 위에 `공명` 텍스트를
자동으로 표시한다. 실패한 소모나 자연 만료에는 표시하지 않는다.
