# 스페셜 클래스 공용 영역 전개

`Rank.SPECIAL` 클래스의 `skills`에 `DomainSkill`을 추가한다. 기존 `AreaDevelopment` 독립 클래스가 아니라 재사용 가능한 스킬이다.

```kotlin
override val skills = listOf(
    DomainSkill(
        definitionId = "my-special/domain",
        cooldown = 120,
        domain = DomainDefinition(
            name = "무너진 도시",
            radius = 16,
            durationTicks = 20 * 30,
            target = DomainTarget.SURROUNDING,
            interior = DomainInteriors::ruinedCity,
            onStart = { domain -> /* domain.players()에 클래스 규칙 적용 */ },
            onTick = { domain -> /* 전투 시간에만 매 틱 호출 */ },
            onEnd = { domain -> /* 클래스 규칙 해제 */ },
        ),
    ),
)
```

`LOOKING_AT_PLAYER`는 시선상의 적 플레이어 한 명과 시전자만 참여시킨다. 대상은 `targetRange`와 영역 내부에 있어야 한다. 지정하지 않은 플레이어는 바깥으로 밀려난다. `SURROUNDING`은 시전 시작 시 반경 안의 플레이어를 참여자로 고정한다. 클래스는 `interior(radius)`로 상대 좌표 `DomainBlock` 목록을 제공할 수 있으며, `DomainInteriors::courtroom`도 제공한다. 구조물로 플레이어의 머리·발을 막는 블록은 생략한다.

## 진행

- 연습 태그가 있는 플레이어는 시선 대상이 없을 때 자신을 대상으로 전개할 수 있다. 심판관은 기록된 죄가 없으면 저장하지 않는 연습용 폭행 증거로 재판을 시험한다(정당방위 선택으로 무죄도 시험 가능). 실제 경기의 대상·범죄 기록 조건과 중복 영역·높이·생존 등 안전 검사는 유지한다.
- 전조에는 확장하는 금색·보라색 이중 마법진, 장막을 타고 상승하는 청백색 빛, 나선형 경선을 표시한다. 지형 전환·이름 공개·전투 시작에는 서로 다른 타격음·공명음과 입자 파동을 재생한다.
- 유지 중에는 경계에 회전하는 봉인 문양과 돔 경선을 표시하고 낮은 공명음을 주기적으로 재생한다. 종료 시 수축하는 마법진·장막 분해·잔광과 해제음을 재생한다. 실제 폭발 피해나 추가 지형 파괴는 없다.
- 파티클은 반경·부피에 비례해 무한히 늘리지 않고 고정 표본을 사용한다(전조 2틱, 유지 4틱, 해제 2틱 간격). 소리는 참여자와 주변 플레이어에게만 재생한다. 독립 타이머 없이 영역 세션이 직접 구동하므로 종료·취소 후 연출 작업이 남지 않는다.

- 시전은 `System.nanoTime()` 기준 실제 3초다. 서버가 멈춘 동안에도 시간은 흐르지만 월드 변경은 다음 서버 틱에서 실행된다.
- 시전 시작부터 시전자 이동·점프·시점·공격·스킬·아이템 조작을 제한한다. 피해를 받는 상태는 유지한다.
- 주변 플레이어에게 왜곡을 부여한다. 이동·시점 속도를 제한하고 공격 속도를 0.001배로 낮추며 공격 충전을 초기화한다. 소유자가 있는 `AbilityRunnable` 전투 효과의 논리 시간은 0.05배로 흐른다. 이미 실행 중인 투사체·범위 효과·애니메이션도 같은 타이머를 사용한다. `SESSION` 작업은 세션 관리용이므로 제외한다.
- 왜곡 중 새 스킬 요청은 느려진 타이머로 지연되고, 실제 실행 시 생존·클래스·침묵·쿨다운 등을 다시 검사한다. 중복 요청은 차단한다. 비용·쿨다운은 성공한 실제 실행에만 적용한다.
- 검은 블록 장막이 바닥에서 위로 물결 모양으로 생성된다. 내부 지형 전환 후 `「영역전개」`, 600ms 후 영역 이름을 표시한다. 표시 후 1800ms에 즉시 제거한다. 서버 지연이 있어도 각 타이틀 단계는 최소 한 프레임 유지된다.
- 타이틀 제거와 함께 왜곡·시전자 제한을 해제하고 `onStart`를 호출한다. 이때부터 `durationTicks`를 센다. 경기 일시정지 동안 전투·해제 연출 시간은 흐르지 않는다.
- 종료 시 내부 구조물이 20틱 동안 바닥으로 가라앉고 장막이 20틱 동안 위에서 아래로 사라진다. 모든 원래 블록 상태를 복원한다.

## 경계와 수명

이동·순간이동·다른 월드 이동을 검사하며, 외부에서 외부로 영역을 가로지르는 이동도 차단한다. 서버 측 재검사로 강제 이동도 교정한다. 목적지 계약이 없는 기존 `MovementSkill`은 내부 사용을 보수적으로 차단하고, 외부에서는 바라보는 방향 128블록 선분이 영역에 들어갈 때 시전부터 거부한다. 목적지에 따른 최종 차단은 순간이동 이벤트에서도 수행한다.

영역 시작부터 완전 해제까지 자기장 축소와 최종 자기장 하강을 정지한다. 현재 자기장 중심을 유지하면서 영역 전체와 퇴출 여유 공간을 포함하도록 최소한 확장하고 종료 시 이전 크기로 돌린다. 성장 모드의 자기장 단계 시계도 정지한다.

시전자 사망·접속 종료·클래스 제거·경기 종료·플러그인 비활성화는 즉시 취소 및 복원한다. 내부 대상 사망은 시전자 영역을 취소하지 않는다. 원상 복구가 충돌하지 않도록 한 월드에서 한 영역만 허용하고, 다른 격리 맵 확장 중에는 전개를 거부한다. 반경은 4–24블록, 내부 구조는 최대 8192블록으로 제한한다. 블록 디스플레이는 저장하지 않는다.

새 클래스의 전투 연출은 `AbilityRunnable`을 사용해야 왜곡 시간에 참여한다. 바닐라 투사체는 별도로 속도와 중력을 느리게 처리하고 종료 시 복원한다. 별도 Bukkit 타이머, 클라이언트 자체 애니메이션 및 투사체 이외 바닐라 엔티티 AI는 이 논리 시계가 자동 제어하지 않는다. 실제 서버에서 연출, 지형·컨테이너 복원, 다중 플레이어 이동과 접속 종료를 확인해야 한다.
