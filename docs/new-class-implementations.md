# 추가 클래스 구현

2026-09-09 기준 설명만 있던 6개 클래스의 실행 기능을 구현했다.
쌍수(`dualwield`), 석궁(`crossbow`), 마탄의 사수(`freikugel`),
종군기자(`warcorrespondent`), 선각자(`pioneer`)를 능력 목록에 등록했다.
이미 등록되어 있던 청부업자(`contractor`)는 변경된 단검 스킬 설명에 맞춰 구현했다.
기존 ID와 스킬 ID는 유지한다.

## 동작

| 클래스 | 구현 내용 |
| --- | --- |
| 쌍수 | 추가 철 검 지급, 보조 손에 검을 든 상태에서 10틱 뒤 절반 피해의 기본 공격. 추가 타격이 다시 추가 타격을 생성하지 않는다. |
| 석궁 | 발사 당시 무기 ID로 석궁 탄환을 식별하고 피해를 4로 제한한다. 최대 3개의 볼트를 80틱 동안 남긴다. 볼트 회수 경로의 적에게 고정 피해를 주고 실제 적중 시 재장전한다. 시선 방향 볼트로 이동하며 경로의 적을 공격한다. |
| 마탄의 사수 | 일반 탄환 6발과 마탄환 1발, 기본 사격 40틱 간격, 마탄 기본 사격의 자해. 패닝은 일반 탄환을 연속 발사하며 반동이 증가하고, 마지막 마탄은 퀵드로우로 사용한다. 탄창이 비면 40틱간 공격·스킬을 잠그고 재장전한다. |
| 종군기자 | 우클릭 촬영과 이동·점프·스킬·사거리 이탈에 따른 종료, 촬영 시간에 따른 20~60틱 대기시간. 부채꼴 촬영에서 동일한 두 적을 연속 20틱 또는 사망 지점을 연속 40틱 촬영하면 1스택을 얻는다. 3스택이면 방송 상태가 된다. 개인 전장 지도에 타인 간 교전과 사망 위치를 표시한다. |
| 선각자 | 속검과 기본 공격 후속타, 4틱 예지 회피 및 반격 보상, 가속·가속탄, 10초 동안 총 5단계 처분, 진동을 두 번 폭발시킨 후 한 번 소모하는 마무리, 화상 잔여 시간에 비례한 작열 피해. |
| 청부업자 | 찌르기 강화와 적중 쿨다운 감소, 대상 뒤·단검 위치로 순보, 암살 투사체와 회수 피해 3회 표식, 십자 단검 생성, 단검 자동 회수와 처리 5스택의 기본 공격 보상. 삭제된 과거 추측 GUI 호출을 제거했다. |

## 설명에 수치가 없던 항목의 기본값

- 쌍수 후속타는 4칸 내에서 보조 손의 검을 유지해야 발동한다.
- 마탄 사거리는 32칸, 패닝 발사 간격은 3틱이다.
- 종군기자 부채꼴은 수평 16칸·120도이며 높이를 무시한다. 방송은 클래스가 유지되는 동안 지속한다.
  교전 표시는 60초 유지하며 사망 기록은 최근 128개까지 보관한다.
- 선각자 후속타/반격 보상 창은 1초, 예지안 회복은 비전투 10초 뒤 초당 1이다.
  스킬 사이 동작 간격은 4틱이며 가속 5스택이면 2틱이다. 작열은 화상 잔여 1초당 상태이상 피해 1이다.
  가속은 기존 설명의 6초당 1스택 제한을 유지하되, **같은 적에게 4초간 피해를 주지 않으면** 만료되도록 정리했다.
  기존의 ‘4초간 스택을 얻지 못하면 만료’ 규칙으로는 스택을 쌓을 수 없었다.
- 청부업자의 찌르기는 3칸/강화 4.5칸, 장부 정리는 반경 4칸이다. 단검은 15초 유지하고 최대 16개까지 보관한다.

## 예지 표시와 수명

공통 광선·원뿔·원형 범위 조회, 장판·투사체·낙하체 생성, 활·석궁 발사, 순간이동과
이동 스킬 발동을 연결했다. 48칸 내의 위협을 선각자에게만 파티클로 표시한다.
투사체와 속도 기반 이동의 표시는 발동 시점의 방향·속도에 따른 예상 경로이며,
이후 조향, 중력, 충돌, 포탈 이동까지 시뮬레이션하는 경로는 아니다.

예약 작업은 `AbilityRunnable`을 사용하고, 재판 중 전투 시간 정지와 클래스 제거·사망 시
작업 해제를 따른다. 재장전·촬영 제한은 `ControlLease`로 자신의 제한만 해제한다.
추가 효과는 회피·무적·보호막 검사를 통과한 양수 피해에 연결되며 훈련 더미에서도 발동한다.

## 검증

- 클래스 팩토리 ID 및 인스턴스 독립성 테스트
- 피해 확정 훅의 취소·보호막·제거된 클래스·출처 컨텍스트 테스트
- 가속 누적/만료/대상 변경, 탄환 상한/소비, 처분 5단계/10초 만료 테스트
- 전체 Gradle 테스트 및 `verifyShadowJarContents`를 포함한 `build`

실제 Paper 서버에서의 다인 전투 검증은 별도로 필요하다. 특히 훈련장에서 볼트 회수 경로,
카메라의 엔티티 우클릭, 단검 순보, 선각자 연속기와 예지 표시를 확인하고,
듀얼 모드에서 재장전·방송 중 클래스 제거 및 재접속 시 제한 해제를 확인한다.
