# 추가 클래스 구현

2026-09-09 기준 설명만 있던 6개 클래스의 실행 기능을 구현했다.
쌍수(`dualwield`), 석궁(`crossbow`), 마탄의 사수(`freikugel`),
종군기자(`warcorrespondent`), 선각자(`pioneer`)를 능력 목록에 등록했다.
이미 등록되어 있던 청부업자(`contractor`)는 변경된 단검 스킬 설명에 맞춰 구현했다.
기존 ID와 스킬 ID는 유지한다.

### 2026-09-10 변경 반영

- 쌍수는 삭제되었으며 팩토리와 활성 클래스 목록에서 제외했다. 아래 쌍수 항목은 9월 9일 구현 이력이다.
- 종군기자는 방송 상태에서도 방송 스킬을 사용할 수 있다. 강화 방송은 조기 취재 완료 없이
  4초간 진행하고, 매 틱 범위 내 적에게 무적 시간을 무시하는 고정 피해 0.1을 준다.
  정상 종료 시 그 순간 범위에 남아 있는 적에게 3초 기절을 적용한다.
  사망·중단·클래스 제거에 의한 작업 정리는 종료 기절을 발동하지 않는다.
- 촬영 부채꼴은 엔티티의 수평 바운딩 박스와 교차 판정하며 Y축은 무시한다.
- 석궁의 볼트·회수·기동 고리, 마탄의 총구·나선 탄도·재장전,
  선각자의 단계별 곡선 검격·진동 충격파, 청부업자의 단검·순보·장부 정리를 보강했다.
- 종군기자에 렌즈 방향 조준 프레임·스캔선·녹화 화면 스캔·강화 방송 종료 연출을 추가했다.
  연출은 기존 피해 타이밍과 분리되며, 추가 지연 작업은 능력 소유자의 수명을 따른다.
- 대행자(`Agent`) 초안은 9월 11일 구현·등록을 완료했다. 아래 최신 항목을 참고한다.

### 2026-09-11 대행자 구현

#### 후속 요청 반영 (아래 초기 구현 기록보다 우선)

무기 피해 기준 통일: 대행자의 실제 아이템은 항상 철 검으로 유지하고 `item_model`로 무기 9종의 외형을 표현한다.
주 손의 공격력 속성은 철 검의 기본 속성(플레이어 기본값 1 + 무기 보너스 5)을 사용한다.
외형별 기본 공격 속도 속성은 기존 재료에서 복사하고, 레이피어·대검의 고유 속도 보정도 유지한다.
메이스 낙하 강타 등 외형 재료의 특수 공격은 발생하지 않는다. 지령·무기 고유 피해 보정과
공통 기본 공격 배율·방어력 계산은 기존 경로에서 그대로 적용한다.

최신 보상·표시 변경: 액션바에는 카두세우스와 지령만 표시하고 피해 배율 상태는 생성하지 않는다.
지령 성공 보상은 가하는 피해 +20%p·받는 피해 -10%p로 변경했다.
실패 시 -5%p/+5%p와 같은 단계 재도전은 유지하며 가하는 피해 하한 50%, 받는 피해 상한 150%를 유지한다.
받는 피해는 반복 성공해도 0% 아래로 내려가지 않는다. 아래의 이전 +5%p 보상·배율 표시 기록은 이 규칙으로 대체한다.

- 액션바는 카두세우스·지령·가하는 피해·받는 피해를 독립 키워드 상태로 표시한다.
  무기 9종도 각각 색상과 설명을 가진 키워드로 표시한다.
- 실패하면 다음 단계로 넘어가지 않고 같은 단계의 목표·제한 시간을 다시 시작한다.
  기존 대상이 유효하면 그대로 유지하고, 소멸했다면 같은 단계에서 새 대상을 선택한다.
  가하는 피해는 50% 아래로, 받는 피해는 150% 위로 변하지 않는다.
  제한에 도달한 뒤 실패를 더 하더라도 숨은 불이익이 누적되지 않아 성공하면 즉시 가하는 피해가 5%p 오른다.
- 실제 경기에서는 지령 대상 지정·진행·최종 사망 확인 모두 PlayerData만 허용한다.
  연습 모드에서만 동물·몬스터를 허용한다.
- 별도 빨간색 스킬 아이템은 지급하지 않는다. 손도끼 우클릭에 내부 도약 강타 스킬을 연결하고,
  침묵·고정·재사용 대기시간 검사와 종료/일시중단 시 정리를 유지한다.
- 무기·스킬·지령 문구는 ‘~한다.’ 형태의 문장으로 표시한다.
  지령 III의 기존 조건(6초 동안 기본 공격 금지 + 도약 강타 적중)은 그대로 유지한다.
- 손도끼의 내려베기, 스틸레토의 관통선, 바스타드 소드의 연속 타격 고리, 레이피어의 삼중 찌르기,
  망치의 충격파, 대검의 넓은 검격, 랜스의 돌진 궤적, 채찍의 곡선, 낫의 영혼 검격을 구분한다.
  무기마다 다른 타격 사운드를 사용한다.
- 지령 완수 시 유리·자수정이 깨지는 소리와 빛 조각이 퍼지는 고리, 후속 차임으로 해금을 연출한다.

선각자 설명의 추가 변경도 반영했다. 예지는 예지안 5 이상일 때만 사용할 수 있으며,
승인된 발동에서만 5를 차감하고 액션바를 즉시 갱신한다. 부족·재사용 대기·침묵·이벤트 취소 시
자원을 소모하지 않는다. 검 우클릭과 스킬 아이템은 같은 사용 경로를 사용하며 기존 4틱 회피와
반격 보상, 파티클·사운드는 유지한다.

- `agent`를 L등급 클래스 목록과 팩토리에 등록했다. 카두세우스와 지령 패시브를 모두 연결했다.
- 기본 공격 3회 적중 또는 변형 후 200 전투 틱마다 현재와 다른 무기로 변형한다.
  자신의 클래스 태그가 있는 무기만 교체하며, 클래스 제거·사망·훈련 종료 시 능력치와 작업은 소유 범위에서 정리한다.
- 손도끼는 무기 우클릭(허공/블록/엔티티) 또는 도약 강타 스킬 아이템으로 발동한다.
  재사용 4초, 착지 시 바운딩 박스 기준 반경 2.5칸에 피해 2. 지형은 변경하지 않는다.
- 스틸레토는 기본 공격의 방어력 20% 무시와 배후 피해 +1을 적용한다.
  바닐라 공격 경로에서도 방어력 무시를 반영하며 저항·보호 마법·흡수 체력은 유지한다.
- 바스타드 소드는 사거리 1.1배와 동일 대상 연속 공격마다 +0.5 피해를 적용한다.
  대상 변경 또는 무기 변형 시 연속 공격 수를 초기화한다.
- 레이피어는 피해 0.75배·최종 검 공격 속도 2.5배, 대검은 최종 검 공격 속도 0.55배와
  전방 3칸 휩쓸기를 적용한다. 후속 피해는 다시 휩쓸기를 생성하지 않는다.
- 망치는 강한 넉백과 1초 기절, 보호막 소모량 2배를 적용한다. 보호막을 넘긴 체력 피해 자체는 두 배가 아니다.
- 랜스는 이동 속도 1.2배, 달리며 실제로 이동한 수평 거리 1칸당 기본 피해 +0.2 (최대 20칸, 피해 +4).
  공격·달리기 중단·비정상 좌표 이동·무기 변경 시 초기화한다.
- 채찍은 사거리 4배와 약한 끌어당김, 낫은 사거리 0.5배·충돌/보더 검사 후 관통 이동을 적용한다.
  낫 타격 직후 다음 틱에 체력이 최대 체력의 10% 미만이면 처형한다. 훈련 플레이어는 판정만 알린다.
- 지령 I~X를 차례로 부여한다. I는 10초, II는 8초, III는 6초, IV~IX는 20초, X는 무제한이다.
  주석의 구체적인 제한 시간을 일반 설명의 20초보다 우선한다.
  VI~IX의 미정 목표는 기본 공격 3회 / 배후 공격 / 달리며 기본 공격 / 도약 강타 적중으로 구현했다.
- III와 IX를 받을 때 손도끼로 변형해 스킬 목표를 수행할 수 있도록 한다.
  적이 한 명뿐이면 II는 보상·불이익 없이 건너뛴다. 대상이 없으면 다음 지령을 대기한다.
  X는 지령 발급 시점의 적들이 모두 사망했는지 검사한다.
- 성공마다 가하는 피해 +5%p, 실패마다 가하는 피해 -5%p·받는 피해 +5%p를 경기 동안 누적한다.
  실패 뒤에도 다음 지령을 받으며, 같은 결과를 여러 번 보상하지 않는다. 가하는 피해 배율의 하한은 0이다.
- 현재 무기·적중 수·변형 시간·지령 목표/시간·피해 배율을 액션바에 표시한다.
  변형 고리, 무기 검격, 도약 궤적과 착지 충격파, 지령 수령/성공/실패 사운드를 추가했다.
- 자동 테스트: 지령 목표/기한/중복 보상/초기화, 무기 공격 속도, 보호막 오버플로,
  바닐라 방어력 무시의 저항·마법·흡수 보존 및 클래스 팩토리 등록을 검증한다.

## 설명에 수치가 없던 항목의 기본값

- 쌍수 후속타는 4칸 내에서 보조 손의 검을 유지해야 발동한다.
- 마탄 사거리는 32칸, 패닝 발사 간격은 3틱이다.
- 종군기자 부채꼴은 수평 16칸·120도이며 높이를 무시한다. 방송은 클래스가 유지되는 동안 지속한다.
  교전 표시는 60초 유지하며 사망 기록은 최근 128개까지 보관한다.
- 선각자 후속타/반격 보상 창은 1초, 예지안 회복은 비전투 10초 뒤 초당 1이다.
  스킬 사이 동작 간격은 4틱이며 가속 5스택이면 2틱이다. 작열은 화상 잔여 1초당 상태이상 피해 1이다.
  가속은 기존 설명의 6초당 1스택 제한을 유지하되, **같은 적에게 4초간 피해를 주지 않으면** 만료되도록 정리했다.
  기존의 ‘4초간 스택을 얻지 못하면 만료’ 규칙으로는 스택을 쌓을 수 없었다.
- 청부업자의 찌르기는 3칸/강화 4.5칸, 장부 정리는 반경 4칸이다. 단검은 15초 유지하고 최대 16개까지 보관한다.

## 예지 표시와 수명

공통 광선·원뿔·원형 범위 조회, 장판·투사체·낙하체 생성, 활·석궁 발사, 순간이동과
이동 스킬 발동을 연결했다. 48칸 내의 위협을 선각자에게만 파티클로 표시한다.
투사체와 속도 기반 이동의 표시는 발동 시점의 방향·속도에 따른 예상 경로이며,
이후 조향, 중력, 충돌, 포탈 이동까지 시뮬레이션하는 경로는 아니다.

예약 작업은 `AbilityRunnable`을 사용하고, 재판 중 전투 시간 정지와 클래스 제거·사망 시
작업 해제를 따른다. 재장전·촬영 제한은 `ControlLease`로 자신의 제한만 해제한다.
추가 효과는 회피·무적·보호막 검사를 통과한 양수 피해에 연결되며 훈련 더미에서도 발동한다.

## 검증

- 클래스 팩토리 ID 및 인스턴스 독립성 테스트
- 피해 확정 훅의 취소·보호막·제거된 클래스·출처 컨텍스트 테스트
- 가속 누적/만료/대상 변경, 탄환 상한/소비, 처분 5단계/10초 만료 테스트
