# 성장 모드

성장은 클래식과 독립된 주 모드이며 듀얼·팀·공동·꼬리잡기 modifier를 함께 사용할 수 있다.
기존 참가 인원, 클래스 선택, 승리, 재접속, 목숨 설정을 따른다. 경기 단위 성장 데이터는 종료 시 초기화한다.

## 시작과 설정

운영자는 `/cw start` 화면 상단에서 성장으로 전환하거나 `/cw growth start`를 실행한다.
`/cw growth start dual team`처럼 조합할 수 있다. 테스트 명령이 활성화된 서버에서는 `/cw test start growth`로 혼자 테스트할 수 있다.
테스트 명령은 운영자 권한과 `internal.testing.commands-enabled: true` 설정이 필요하다.
`/cw test start growth dual`처럼 기존 옵션과 조합할 수 있으며 `growth`를 포함한 모든 옵션을 Tab으로 자동완성한다.
테스트 경기에서는 최소 참가 인원 제한과 자동 승리 종료를 해제하지만, 성장 모드의 맵·자기장·고정 스폰 검증은 유지한다.
`/cw stop`은 기존과 같이 모든 경기 자원을 정리한다.

성장 모드는 `border.enabled: true`, `scatter.fixed-spawn.enabled: false`가 필요하다.
초기 자기장은 64~768블록이며 최소 자기장이 초기 크기의 절반 이하여야 한다. 정수 블록 단위 지역 좌표에 맞춰 초기 크기는 내림하고 중심을 정렬한다.
지역당 최소 자기장 공간을 확보하지 못하는 지형에서는 시작할 수 없다.
**맵에 따라 지역 생성과 시작이 실패하거나 이동 경로에 문제가 발생할 수 있다.** 이 경고는 모드 선택과 성장 설정 화면에 항상 표시된다.

| 명령 | 권한 / 용도 |
| --- | --- |
| `/cw growth stats` | 참가자의 레벨·경험치·스탯, 클릭 1점 / Shift 전체 배분, 클래스 아이콘으로 현재 효과 확인 |
| `/cw growth items` | 보유 장비 장착·해제, 같은 슬롯의 장비는 교체 |
| `/cw growth regions` | 지역 이름·상태·통행 가능한 이웃 번호·예정/진행 중 이벤트 좌표 |
| `/cw growth config` | 운영자 설정 GUI. 변경은 다음 경기부터 적용 |
| `/cw growth start [modifier...]` | 운영자 경기 시작 |
| `/cw growth nextphase` | 운영자 다음 낮/밤 진행. 최종 지역과 일시정지 상태에서는 불가 |
| `/cw growth spawnmobs` | 운영자 일일 몬스터 재생성 |
| `/cw growth xp <플레이어> <1~100000>` | 운영자 경험치 지급 |
| `/cw growth give <플레이어> <장비 ID>` | 운영자 장비 지급 |

기본 조작은 **레벨업 아이템 우클릭 → 스탯 배분**, **Shift + F → 장비 보관함**이다. 위의 stats/items 명령은 호환용으로 유지한다.
장비 창에는 현재 보유한 장비만 표시하며, 장비가 없으면 획득 안내를 표시한다. 일반 F키의 클래스 조작은 그대로 유지한다.

## 지역과 자기장

1. 최대 네 청크를 동시에 비동기 로딩하고, 메인 스레드에서 thread-safe 청크 스냅샷을 얻는다.
2. 별도 작업에서 지표·머리 공간·고도·바이옴·나무·물가를 분석한다. 물·용암·위험 블록·나무 꼭대기는 스폰 후보에서 제외한다.
3. 서로 다른 비율의 직사각형을 지형 경계·통행 단절과 난수에 따라 분할한 뒤 인접 조각을 결합한다. 결과는 직각 모서리만 가진 혼합 직사각형 지역이다.
4. 각 지역의 가장 큰 보행 가능 연결 영역을 구한다. 한 블록 이하 높이 차이로 실제 접하는 보행 지점이 있을 때만 인접 지역으로 연결한다.
5. 모든 지역의 통행 그래프 연결성과 최종 자기장이 들어갈 정사각형을 검증한다. 기본 16지역부터 시도하고 실패하면 최소 4지역까지 줄인다.
6. 청크 준비는 180초, 지역 생성은 시도 횟수와 30초 분석 예산으로 제한한다. 중단된 경기의 결과는 게시하지 않는다.

기본 낮/밤 길이는 각각 120초다. 1일차 낮 시작 시 첫 경고 지역을 노란색으로 표시하고 다음 밤에 빨간색으로 만든다.
이후 전환마다 기존 경고를 금지로 만들고 새로운 경고를 선택한다. 노란 지역은 **다음 시간대**에 금지된다(밤에 노란색이면 다음 낮에 빨간색).
아직 안전한 지역들은 항상 연결되어 있고, 모든 경고 지역에는 안전 지역으로 직접 통하는 출구가 남는다.
동시에 여러 지역을 경고로 지정할 때도 전체 배치의 연결성을 다시 검사한다.

금지 지역과 경기 영역 밖에서는 기본 초당 2 피해를 받는다. 기존 환경 피해·무적 규칙과 `world-border` 피해 배율을 따른다.
초기 월드보더는 고정된다. 마지막 지역이 되면 해당 지역에 미리 확보한 정사각형을 향해 월드보더가 기본 120초 동안 최소 크기까지 줄어든다.
성장 모드에서는 클래식의 상공 자기장 하강을 실행하지 않고 최소 자기장을 유지한다. 최종 지역 전에도 금지된 지역은 계속 금지 상태다.
경기 일시정지 또는 별도 능력 맵 전송 중에는 성장 시계·축소·지역 피해 진행을 멈춘다.

전투 지도는 안전 지역의 지형을 유지하고 경고/금지를 노랑/빨강으로 덮으며, 경계·지역 이름·한정 아이템/몬스터의 예정 및 현재 위치를 표시한다.
지도 경계는 흰 중심선과 검은 외곽선으로 강조한다. 월드에서는 주변 24블록 내 경계에 청록(안전)·노랑(경고)·빨강(금지) 파티클을 표시한다.
양쪽 지역의 상태가 다르면 더 위험한 쪽의 색상을 사용한다. 플레이어당 가까운 128개 경계 지점만 표시하며, 파티클을 위해 청크를 추가 로드하지 않는다.
지역을 건너도 텍스트를 보내지 않는다. 보스바에는 일차·낮/밤·전환 시간을 표시하며, 시간 전환 안내에서 다음 금지 지역 목록은 생략한다.
지역 이름은 아르덴 숲·벨로라 해변처럼 고유 지명과 지형을 조합한다. 최대 32지역이 동일 지형이어도 지명을 중복하거나 숫자를 붙이지 않는다.

## 성장과 계수

레벨 1, 배분 스탯 0으로 시작한다. 필요 경험치는 기본 `60 + (현재 레벨 - 1) × 25`이고 최대 레벨은 30이다.
레벨업마다 3포인트, 기본 최대 체력 2를 얻는다. 체력은 기존 속성 합성 계층에서 클래스·버프 효과와 함께 적용한다.
레벨과 경험치 진행률은 Minecraft 경험치 바에 표시하고, 액션바에는 기존 클래스 자원·상태이상만 표시한다. 최대 레벨에서는 바를 가득 채운다.
바닐라 경험치 획득은 성장 경험치와 합산하지 않으며, 경기 종료 시 기존 경험치 정보를 복원한다.
레벨업 시 본인에게 사운드와 파티클을 재생한다(은신 위치가 적에게 노출되지 않도록 본인에게만 전송).
미배분 포인트가 있으면 빈 핫바 칸, 이후 일반 인벤토리 칸 순서로 레벨업 아이템을 지급한다. 모두 가득 찬 경우 안내 후 빈칸이 생기면 자동 지급한다.
아이템은 우클릭으로 배분 창을 열고, 모든 포인트를 배분하면 사라진다. 인벤토리에 들어간 아이템도 인벤토리에서 우클릭할 수 있다.
이 UI 아이템은 소유자·경기에 귀속되며 이동·드롭을 차단한다. 일시정지·사망 중에는 배분/장착할 수 없다.
힘·민첩·지능·운을 직접 배분한다. 장비 스탯은 별도로 합산하며 교체 시 해당 장비의 기여분만 제거한다.
민첩은 공통 이동 속도(최대 +15%)와 공격 속도(최대 +35%)에도 영향을 준다.

모든 클래스에는 직업 유형에 따른 주스탯·부스탯 프로필이 있다. 스킬·기본 공격·지속 피해는 공통 피해 계산 경로에서 계수를 받는다.
듀얼 무기는 사용한 무기 ID, 투사체는 발사 시 기록한 ID, 능력과 상태 효과는 능력 실행 출처로 계수를 결정한다.
전체 플레이 가능 클래스에 공격 성향을 명시하고, 랭크 자체가 아닌 기본 공격/스킬/소환 중심 여부로 성장 기울기를 구분한다. 초기 수치는 실전 밸런스 검증 전 값이다.

`W = 주스탯 × 1.5 + 부스탯 × 0.6`은 **피해 계산에만** 사용한다. 아래는 원래 수치에 더할 백분율이다.

| 항목 | 추가 백분율 | 최대 증가 |
| --- | --- | --- |
| 기본 공격 피해 | W × 클래스별 기본 공격 가중치 | **제한 없음** |
| 스킬·패시브·상태 피해 | W × 클래스별 스킬 가중치 | **제한 없음** |
| 회복 | 지능 × 0.80 | +100% |
| 쿨다운 흐름 | 지능 × 0.50 | +50% |
| 사거리 | 민첩 × 0.20 | +25% |
| 밀치기 | 힘 × 0.50 | +50% |
| 상태·장판 지속시간 | 지능 × 0.40 | +50% |
| 일반 상태 위력·마나/충전 최대치 | 지능 × 0.60 | +100% |
| 출혈·진동 위력/최대치 | 힘 × 0.60 | +100% |
| 보호막·유예 체력 | 힘 × 0.80 | +100% |
| 이동/공격 속도 버프·둔화 위력 | 민첩 × 0.50 | +50% |
| 적용 대상 확률 | 운 × 0.50 | +50% |

기본 공격 중심은 기본 공격 `W×1.4` / 스킬 `W×0.65`, 복합은 각각 `W×1`, 스킬 중심은 `W×0.25` / `W×1.4`, 소환·패시브 중심은 `W×0.2` / `W×1`이다.
이전의 성장 피해 300% 제한은 제거했다. 석궁의 성장 경기 중 절대 피해 4 제한도 해제했다.
기본 무기 피해뿐 아니라 패시브가 더하는 기본 피해 보너스에도 출처 클래스의 성장 가중치를 한 번 적용한다.
클래식 피해 수치, 생존 기술의 체력 하한, 피해 무효화, 평화주의자의 기본 공격 0 규칙은 유지한다.
쿨다운 흐름 150%는 실제 대기시간 약 66.7%다. 상태 지속시간·위력은 기존 정수 표현으로 반올림한다.
민첩 주스탯/힘 부스탯이어도 민첩이나 힘만 올려서는 쿨다운이 줄지 않는다. 기본 설정에서는 지능을 올려야 한다.
스킬·무기·패시브 설명은 성장하는 수치 바로 옆에 담당 스탯과 계수를 표시한다. 주·부스탯이나 효과별 계수를 별도 요약 목록으로 덧붙이지 않는다.
표시 숫자는 현재 배분과 장비를 반영하며, 원래 설명 숫자보다 증가한 부분만 초록색이다. 감소하거나 동일한 숫자는 원래 색을 유지한다.
스탯 GUI의 클래스 아이콘으로 현재 설명을 확인할 수 있다. 구체적인 표기·반올림 규칙은 [클래스별 성장 수치](growth-class-scaling.md#설명의-수치-표기)를 참고한다.

행운아·룰렛·영웅·공포·대장장이의 유리한 발동 확률에는 운을 적용한다. 원래 85% 미만인 확률은 최대 85%로 제한한다.
다모클레스의 자기 처형 같은 불리한 확률은 운이 높을수록 감소한다. 카드 합계 규칙·랜덤 좌표·연출 난수 등은 그대로 유지한다.
밀치기는 기본 공격과 황소·뚱보·요원·공포·마탄·평화주의자의 직접 밀치기에 적용한다. 이동기/텔레포트의 좌표 변환은 별도 규칙을 유지한다.
마나·충전과 함께 클래스별 소환 개수·장전 수·자원 한도도 개별 스탯에 연결한다. 이기어검은 민첩 20당 어검술 +1(최대 +6), 지능 10당 인피니트 +1(최대 +18)이다.
소환/설치 개수는 배치·공전·연쇄 처리 한도도 함께 반영하고, 충전 수는 실제 자원 표시와 회복 한도에 반영한다.
장비 해제 후 지속 소환/자원은 다음 갱신에 새 한도를 적용한다. 이미 발동한 일회성 소환은 시전 시점 수치를 유지한다.
카드 합 21, 엑조디아 다섯 부위, 고정 무기/행성 종류, 콤보 단계 같은 규칙 숫자는 무작정 늘리지 않는다.
고유 증가표와 적용 방식은 [클래스별 성장 수치](growth-class-scaling.md)를 참고한다.

클래스별 재정의 예시:

```yaml
growth:
  classes:
    ice-wizard:
      primary: INTELLIGENCE
      secondary: AGILITY
      primary-percent: 1.5
      secondary-percent: 0.6
      basic-damage-weight: 0.25
      skill-damage-weight: 1.4
      effects:
        cooldown:
          stat: INTELLIGENCE
          percent: 0.5
```

## 사냥·장비·이벤트

기본 지역당 12개 캠프(소·돼지 각 3마리, 좀비·스켈레톤 각 3마리), 최대 192마리를 생성한다. 동물은 정지하며 몬스터는 캠프 주변에서 전투한다.
안전한 지점을 충분히 확보하지 못하면 실제 수는 줄어든다. 전체 상한은 지역별로 순환 배분하여 앞쪽 지역에만 캠프가 몰리지 않게 한다.
`growth.mobs.per-region`은 0~32, `growth.mobs.maximum`은 0~512에서 설정할 수 있다. 0이면 일반 캠프를 생성하지 않는다.
업데이트 후 첫 실행에서 옛 기본값(4마리/96마리/드롭률 0.18)만 각각 12/192/0.45로 갱신한다. 다른 사용자 설정값은 유지한다.
`growth.population-revision: 1`을 기록한 뒤에는 이전 수치를 다시 지정해도 더 이상 자동 갱신하지 않는다.
지역을 벗어나거나 캠프에서 12블록 이상 멀어지면 원위치로 돌아간다. 고정 캠프는 지역의 검증된 보행 영역에서 선택한다.
새 낮마다 기존 성장 몬스터를 정리하고, **전체 참가자의 산술 평균 레벨을 반올림한 값**으로 다시 생성한다. 그날 생성한 몬스터의 레벨은 고정된다.
기본 체력은 `20 + 레벨 × 5`, 근접 공격력은 `2 + 레벨 × 0.4`, 경험치는 `30 + 레벨 × 3`이다.
이름표에 현재/최대 체력을 기본 표시하고 0.5초마다 갱신한다. `growth.mobs.show-health: false`로 체력만 숨길 수 있으며 성장 설정 GUI에서도 전환한다(다음 경기 적용).
몬스터는 틱당 최대 4마리씩 생성하고, 금지 지역에는 재생성하지 않는다. 일반 월드 생명체는 성장 보상 대상이 아니다.
플레이어 처치는 기본 100 경험치다. 팀원·자기 자신 처치로는 경험치를 얻지 않는다.

3,454종 장비(무기·방어구·장신구 각 864종, 유물 862종)는 무기 보조·방어구·장신구·유물의 네 전용 슬롯에 장착한다. 플레이어의 실제 방어구 슬롯이나 클래스 스킬 슬롯을 소비하지 않는다.
장비 보관함은 페이지당 45종을 표시하며 하단 화살표로 이동한다. 장착·해제 후에도 현재 페이지를 유지한다.
방어구는 몸통의 갑옷 외형으로, 무기 보조는 등에 멘 검으로, 장신구는 어깨 장식으로, 유물은 허리 장식으로 표현한다.

장식은 플레이어를 볼 수 있는 근처 관전자/플레이어에게만 보이며, 투명·수영·활강 중에는 부착 장식을 숨긴다.

### 한정 이벤트

기본 아이템 이벤트는 2일차 낮 세계수의 심장, 3일차 밤 달의 핵이다. 기본 한정 몬스터는 1일차 밤 숲/평원의 세계수의 심장 수호자(좀비), 2일차 밤 지형 제한 없는 달의 핵 수호자(스켈레톤)다. 처치자에게 무작위 전설 또는 초월 장비를 지급한다. 수호자의 이름은 기존 이벤트 테마를 유지한다. 각 이벤트는 경기당 1회, 90초 동안 등장한다.

등장 예정 시점의 안전 지역을 우선 사용하고, 해당 지형이 경고 지역에만 남아 있으면 아직 출입 가능한 경고 지역도 사용한다.
경고 지역 이벤트는 다음 지역 전환에서 금지되면 종료될 수 있다. 금지 지역에는 생성하지 않는다.
지역 지형 태그는 설정의 대소문자와 앞뒤 공백을 무시한다.
이벤트 등장 후에는 주변 청크를 로딩 상태로 유지해 플레이어가 멀리 있다는 이유로 이벤트 엔티티와 마커가 사라지는 것을 방지한다.
사용이 끝난 청크 유지 요청은 정기 정리 및 경기 종료 시 해제한다.

`/cw growth regions`에서 예정/활성 이벤트 좌표뿐 아니라 생략 사유도 확인할 수 있다.
지역 수가 적거나 한 번에 여러 지역을 금지하여 예정 날짜 전에 최종 지역에 도달하면 해당 이벤트는 생략된다.
이 경우 `growth.regions`의 지역 수를 늘리거나 이벤트의 `day`/`night`를 앞당겨야 한다.
필요한 지형이 없거나 예정 위치가 막힌 경우도 별도로 안내한다.
준비 시 금지 순서를 미리 계산해서 예정 시간에 안전한 지역과 실제 좌표를 배정한다. 해당 지형이 없거나 경기의 지역 단계가 너무 짧으면 준비 중 생략 사유를 알린다.
등장 전부터 지도에 회색 이름과 목표 지점 아이콘으로 이름·예정 일차/낮밤을 표시한다. 등장 후에는 빨간 X와 금색 굵은 이름(★ 등장 중)으로 강조한다.
등장 후 이동한 몬스터는 현재 위치로 표시한다. 예정 위치가 막히면 다른 곳으로 옮기지 않고 해당 이벤트를 생략하며 마커를 제거한다.
이벤트 아이템을 주우면 즉시 보관함에 들어가고 마커가 사라진다. 한정 몬스터는 처치 즉시 마커가 사라지며 처치자에게 전설 90%·초월 10%로 추첨한 장비를 지급한다.
만료·엔티티 제거·해당 지역 금지 시에도 마커가 사라지며 같은 이벤트가 다시 표시되거나 재등장하지 않는다. 한정 몬스터는 일반 몬스터의 일일 재생성 대상이 아니다.

```yaml
growth:
  events:
    custom-relic:
      day: 2
      night: false
      terrain-tags: [forest, plains]
      reward: world-tree
      lifetime-seconds: 90
      # 선택 사항: 생략하면 아이템, 지정하면 해당 몬스터가 등장한다.
      # 몬스터의 reward는 수호자 이름의 테마이며 실제 보상은 전설/초월 전체에서 추첨한다.
      mob-type: SKELETON
```

빈 `terrain-tags: []`는 모든 지형을 허용한다. 유효 태그는 `forest`, `beach`, `mountain`, `snow`, `desert`, `ruins`, `plains`다.
`mob-type`은 `ZOMBIE`, `SKELETON`, `SPIDER`, `HUSK`, `STRAY`, `DROWNED`, `WITHER_SKELETON`을 지원한다. 잘못된 종류는 해당 이벤트 설정을 제외한다.
기존 기본 이벤트 두 개는 아이템 형태를 유지하며 한정 몬스터 두 개가 기본으로 추가된다. 추가 몬스터 이벤트는 `mob-type`으로 설정한다. 업데이트 후 첫 시작 시 누락된 기본 수호자 설정을 한 번 추가하며, 기존 동일 ID의 설정과 이벤트 비활성화 및 명시적으로 비운 이벤트 목록은 유지한다. 이후 삭제한 이벤트는 다시 추가하지 않는다. 일반 야생 동물/지역 몬스터는 이 한정 이벤트 마커의 대상이 아니다.
이벤트만 비활성화하려면 `growth.events-enabled: false`를 설정한다.

## 수명과 검증 범위

레벨·스탯·보관함·장착·장비 내부 쿨다운은 경기의 UUID별 데이터로 유지해 재접속과 추가 목숨의 재등장에 이어진다.
경기 종료 시 성장 몬스터·이벤트 아이템·예약 작업·지도 렌더러·성장 속성을 해제하고 원래 월드보더 설정과 기존 참가자 스냅샷을 복원한다.
월드에 저장되지 않는 성장 엔티티에는 전용 태그를 붙이고, 이후 청크 로드에서도 현재 경기 소유가 아닌 잔여 엔티티를 제거한다.
서버 재시작 후 경기 자체를 재개하는 영속 저장은 제공하지 않는다.

자동 테스트는 정수 좌표 경계, 모든 칸의 단일 소유권, 기본 320블록/16지역 생성, 복수 경고의 연결성·탈출구,
최종 정사각형 포함, seed 재현성, 불가능한 맵의 종료, 취소, 레벨·포인트 보존, 장비 교체, 계수 상한, 모드 직렬화 등을 검증한다.
기존 회귀 테스트 및 Shadow JAR 필수 클래스 포함 검사도 실행한다.

실제 Paper 서버의 다양한 맵에서 전체 경기를 수행하는 플레이테스트 및 TPS 측정은 별도로 필요하다.
특히 지형을 바꾸는 능력 실행 후 출구 유지, 별도 맵 이동 중 일시정지, 최종 자기장 안의 다인 재등장,
재접속 시 스킬/장비 상태, 일일 몬스터 수와 장비 효과를 확인해야 한다. 스냅샷 이후 블록을 바꾼 지형은 자동 재분할하지 않는다.
클래스 승률·게임 길이·실제 처치 시간에 기반한 최종 밸런스 튜닝은 이 자동 테스트만으로 검증할 수 없다.

신규 고유 효과 24종의 조건과 수치는 [고유 효과 장비 목록](growth-unique-equipment.md)을 참고한다. 기존 20종과 합쳐 총 44종의 고유 효과를 제공한다.
